Attempt 3. The previous two started with a math phase and died there. This one

## The core rule

**The gradient checker is the teacher.**

You write a backward pass from rough intuition. Then:

```python
def grad_check(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)
```

tells you in under a second whether you were right. Math is a debugging tool,
not an entry fee. You are never "not ready enough to start."

## The entire math surface

Five items. That's all that stands between here and a trained transformer.

1. **Chain rule** as "multiply the local derivatives along the path"
2. **Eight primitive derivatives**: `+`, `*`, `pow`, `exp`, `log`, `tanh`/`relu`, `max`, `sum`
3. **Matmul backward**: `dA = dC @ B.T`, `dB = A.T @ dC` (derivable from shape-matching alone)
4. **Softmax + cross-entropy** collapses to `(p - y)`. One derivation, done once, reused forever
5. **Broadcasting**: broadcast in forward means sum over the broadcast dims in backward

You meet each one at the exact moment it blocks a line of code. Never before.

## Operating rules

### Session shape

| Phase | Duration | What |
|---|---|---|
| Open | 2 min | Run the test suite. It passes, or you have today's task. |
| Work | 90 min | One unit's worth. Not more. |
| Close | 3 min | Commit. One line in `LOG.md`: what works now, what's next. |

Five sessions a week ≈ 8-10 hours.

**Never end a session on a broken build.** If it's broken when time is up,
`git stash` and write the symptom in `LOG.md`.

### Stuck protocol

45 minutes of genuine stuck, then ask. Ask for **the concept, not the code**.

- Good: "Why is my broadcast gradient N times too large?"
- Bad: "Fix this function."

The second one gets you a working repo you don't own.

### Agent policy

**Claude Code is banned through Unit 10.** If an agent writes the autograd
engine, the project is void. From Unit 11 it may be used for training plumbing,
data loading, and infra only.

### The two consistency rules

1. **Minimum viable day is 20 minutes.** Run the tests, reread yesterday's code.
   That counts as showing up. Never skip two consecutive days.
2. **Never restart.** If you fall off for three weeks, resume at the last
   passing test. Not Unit 1. The urge to "start clean" is what killed attempts
   1 and 2.

# The 12 Units

Units, not weeks. If a unit takes nine days, it took nine days.

---

## Unit 1 — The expression graph

- [x] `Value` class holding `data`, `grad`, `_prev`
- [x] `__add__`, `__mul__`, plus `__radd__` / `__rmul__` for `2 * x`
- [x] `__repr__` that prints usefully
- [x] `topo_sort()` returning nodes in dependency order
- [x] A drawn or printed graph of `a*b + c`

**Math needed:** none.

**Done when:** `(a*b + c).data` is correct and `topo_sort` returns parents
before children on a graph with a shared subexpression (a diamond).

**Trap:** using a list instead of a set for `_prev`, or forgetting that a node
can appear twice in one expression (`x * x`).

---

## Unit 2 — Backward, and the checker

- [x] `_backward` closures on `+` and `*`
- [x] `backward()` walking the reversed topo order, seeding `self.grad = 1.0`
- [x] `grad_check(f, x)` using central differences
- [x] `pow`, `tanh`, `exp`, `relu` with gradcheck passing on each
- [x] `tests/test_gradcheck.py` with one test per primitive

**Math arrives:** chain rule, eight primitive derivatives.

**Done when:** every primitive passes gradcheck to within 1e-6, and you can say
in one sentence why gradients **accumulate** (`+=`) rather than assign.

**Trap:** `=` instead of `+=` in `_backward`. Silently wrong on any node used
twice. Your gradcheck on `x * x` catches it. Write that test.

---

## Unit 3 — Train something (the milestone)

- [ ] `Neuron`, `Layer`, `MLP` classes
- [ ] `parameters()` returning a flat list
- [ ] A toy 2D dataset generated by hand (two interleaving moons or spirals)
- [ ] MSE or hinge loss
- [ ] Training loop: forward → backward → step → `zero_grad`
- [ ] Loss printed each epoch, and it goes **down**

**Math needed:** none. This is plumbing.

**Done when:** the loss curve descends and the decision boundary separates the
two classes.

**This is the unit that makes it real.** Under three weeks in and you have a
neural network you built from nothing, learning. Both previous attempts died
before producing anything that ran. Do not skip ahead to Unit 4 the same day.
Sit with it working.

---

## Unit 4 — Break it deliberately

Reproduce each failure, observe the signature, then fix it.

- [ ] Remove `zero_grad`. Watch what the loss does.
- [ ] Set the learning rate to 10. Watch it explode.
- [ ] Set it to 1e-8. Watch it flatline.
- [ ] Remove the nonlinearity. Confirm it can no longer separate the moons.
- [ ] Initialize all weights to zero. Explain why every neuron stays identical.
- [ ] Write each signature into `LOG.md` under "failure modes"

**Math needed:** none. This is pattern recognition.

**Done when:** you can look at a loss curve and name the bug before reading
the code. This unit pays for itself ten times over in Unit 11.

---

## Unit 5 — Tensors

- [ ] `Tensor` class wrapping a numpy array, same graph machinery
- [ ] Elementwise ops with correct backward
- [ ] `matmul` forward and backward
- [ ] Broadcasting: the `unbroadcast` helper that sums over expanded dims
- [ ] `sum`, `mean`, reshape, transpose
- [ ] Gradcheck extended to arrays (perturb one element at a time)

**Math arrives:** matmul backward (item 3), broadcasting backward (item 5).

**Done when:** gradcheck passes on `(A @ B + bias).sum()` where `bias`
broadcasts across the batch dimension.

**Trap:** broadcasting. This is the single most common source of silently
wrong gradients in a hand-rolled engine. If a gradient's shape doesn't match
its tensor's shape, you have this bug. Assert shapes in `_backward`.

---

## Unit 6 — Real layers, real data

- [ ] `Linear`, `ReLU`, `Sequential`
- [ ] `softmax` and `cross_entropy` (fused, not separate)
- [ ] MNIST loaded from raw idx files, no torchvision
- [ ] Batching
- [ ] Train to >90% test accuracy on CPU

**Math arrives:** softmax + cross-entropy → `(p - y)` (item 4). Derive it once,
by hand, on paper, for a 3-class example. Then never again.

**Done when:** >90% on the MNIST test set, from your own engine.

**Trap:** computing softmax then log separately overflows. Subtract the max
before exponentiating. You will hit `nan` and this is why.

---

## Unit 7 — Optimizers

- [ ] `SGD`
- [ ] `SGD + momentum`
- [ ] `Adam` (bias correction included)
- [ ] All three on the same MNIST task, curves plotted on one axis

**Math arrives:** exponential moving averages. Ten minutes.

**Done when:** you can explain from your own plot why Adam converges faster
early and what the bias correction term is actually correcting for.

---

## Unit 8 — Language, the dumbest version

- [ ] A text corpus (tiny Shakespeare, or your own writing)
- [ ] Character-level tokenizer: `encode`, `decode`, vocab
- [ ] Batched `(x, y)` sampling with a context window
- [ ] Bigram model: an embedding table, nothing else
- [ ] Train it, sample from it, read the garbage it produces

**Math needed:** none.

**Done when:** it generates text that is clearly garbage but has the right
character frequencies. The garbage is the point. It gives you a baseline
loss number that everything after must beat.

---

## Unit 9 — Attention, one head

- [ ] Q, K, V projections
- [ ] Scaled dot-product attention
- [ ] Causal mask via `-inf` before softmax
- [ ] Gradcheck the whole attention block
- [ ] Drop it into the Unit 8 model, confirm loss improves over bigram

**Math arrives:** why divide by `sqrt(d_k)`. One paragraph: without it, the dot
products grow with dimension, softmax saturates, gradients vanish.

**Done when:** gradcheck passes on attention and validation loss beats the
bigram baseline.

**Trap:** masking after softmax instead of before. Fills the mask positions
with nonzero probability. Test: assert that row `i` of the attention weights
has zeros in every column `> i`.

---

## Unit 10 — The full block

- [ ] Multi-head attention (split, attend, concat, project)
- [ ] Position embeddings
- [ ] LayerNorm with backward, gradchecked
- [ ] Feedforward: `Linear → GELU/ReLU → Linear` with the 4x expansion
- [ ] Residual connections
- [ ] Stack N blocks into a working `GPT` class

**Math arrives:** LayerNorm backward is the ugliest derivative in the whole
project. Do **not** derive it by hand. Write your best guess, let gradcheck
tell you where it's wrong, iterate. This is the rule working as designed.

**Done when:** a 4-layer, 4-head model forward-passes with correct shapes and
gradchecks end to end.

---

## Unit 11 — Train it for real

- [ ] Move tensors to the 4060 (cupy, or accept a slow numpy run)
- [ ] Train/val split, validation loss logged separately
- [ ] Checkpointing every N steps
- [ ] Learning rate warmup + cosine decay
- [ ] Deliberately overfit a tiny subset first (loss → ~0). If it can't, the
      model is broken, not undertrained.
- [ ] Full run. Loss curve saved.

**Math needed:** none.

**Done when:** the model produces text with real words, plausible punctuation,
and something resembling sentence structure.

**Agent policy relaxes here.** Claude Code may write the data loader,
checkpoint IO, and plotting. Not the model.

---

## Unit 12 — Inference and ship

- [ ] Greedy, temperature, top-k, top-p sampling. Compare outputs.
- [ ] KV cache. Measure tokens/sec before and after.
- [ ] `sample.py` CLI
- [ ] README with the loss curves, sample outputs, and what you learned
- [ ] Push it

**Math needed:** none.

**Done when:** it's public and someone else could run it.

## LOG.md format

One line per session. That's the whole ritual.

```
2026-09-02  U1  topo_sort works on diamond graphs. Next: __radd__ for `2 * x`.
2026-09-03  U1  Done. Next: _backward closures.
2026-09-04  U2  add/mul backward pass gradcheck. Next: tanh.
```

If you go quiet for a while, you reopen this file, read the last line, and
resume there. That's the whole anti-restart mechanism.
